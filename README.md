## 👋 About

This is a **100-day programming challenge** in which I revise and strengthen my programming knowledge by learning something new every day and building in public.

The repository mainly contains:

- ☕ **Java development**: core concepts and practice programs
- 🌱 **Spring Boot stack**: backend development with Spring Boot
- 🧠 **Daily DSA problems**: data structures and algorithms practice
- 📝 **Notes and projects**: what I learned along the way, and things I built with it

Everything here is committed publicly, so every day's progress (and every mistake) is part of the story.
